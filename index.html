FishTools Studio

v0.6.10
Active Development Stage (Alpha)

FishTools Studio is a browser-based motion graphics and video editor. Rendering calculations and project storage run entirely locally on your device.

v0.6.10 Latest Oct 31, 2026
New
Texture Flux Background Fill Effect & Automated WASM Bundle Compilation (`effects/backup/texture_flux.js`, `effects/effects.wasm`, `effects/manifest.json`, `effects/loader.js`, `scripts/sync-effects.js`, `js/media/frame-extractor.js`) Added `Texture Flux` (`id: 'texture-flux'`) under the `background` category, synthesizing animated multi-octave swirling turbulence (`Flux Scale`, `Flux Speed`, `Flux Color 1`, `Flux Color 2`, `Roughness`, `Opacity`, `Blend`) directly as a full layer/alpha fill without the outer outline ring of `Solid Aura (Flux)`. Integrated automatic SplitMix64 encryption and `effects.wasm` compilation into `scripts/sync-effects.js` so `npm run sync:effects` and `npm test` automatically rebuild `effects/effects.wasm` whenever effects are added or modified.
New
Web Audio Clip Scheduler (default-enabled) (`js/media/fish-audio-scheduler.js`, `js/media/fish-audio-engine.js`, `js/editor/editor-timeline-core.js`, `js/media/fish-export-engine.js`, `editor.html`, `desktop.html`) `FishAudioScheduler` decodes each audio / video clip's audio once into an `AudioBuffer` (sequential decode queue, LRU memory budget 640 MB desktop / 192 MB mobile) and plays it with an `AudioBufferSourceNode` scheduled on the `AudioContext` clock (250 ms tick, 2 s lookahead). The same clock (output-latency compensated) drives the playhead during cached playback, so picture (`VideoFrameExtractor` frames rendered at timeline time) and sound share one sample-accurate clock and cannot drift; loop / seek simply reschedule sources instead of seeking media elements. Supports root and nested `precomp` clips (with parent window clamping, source offset, speed, and gain scaling), reverse playback (`speed < 0` via cached sample-reversed `AudioBuffer`), time remap (`speedMode === 'time_remap'` on layer or parent precomp) and speed keyframes (`keyframes.speed`) via `playbackRate` automation, volume keyframes / expressions via `GainNode` automation, and per-voice Web Audio effect chains (`reverb`, `delay` on clip and parent precomp). Enabled by default (`localStorage.setItem('oft_audio_engine', 'legacy')` to force legacy element engine).
Fixed
Playback Lag From Per-Tick Media Lookups (`js/editor/editor-media.js`) `getOrLoadLayerMedia` runs on every playback tick and triggered `VideoFrameExtractor.extractLayerRange`, which begins with an IndexedDB `getProjectMedia()` query, 60–120 times per second even when every frame was cached. Requests are now throttled per layer (once per 1.5 s, never while one is in flight).
Fixed
Stutter After Loop / Seek (`js/editor/editor-timeline-core.js`) The playhead no longer hard-snaps to the media element audio clock (which stalls after every seek); wall-clock drives motion and audio pulls it gently, with a 450 ms settle window after play / loop.
Fixed
Export Dimension Fallback (`js/editor/editor-export.js`) MediaRecorder bitrate now uses the already-resolved composition dimensions instead of a hardcoded `1080p` / `16:9` fallback.
v0.6.9 Oct 31, 2026
Improved
Adaptive Export Bitrate & H.264 High Profile (`js/media/fish-export-engine.js`, `js/editor/editor-export.js`) Replaced fixed 16 / 25 / 50 Mbps export bitrates with `computeExportVideoBitrate`, which scales with resolution and frame rate (1080p30 targets: Light 6, Normal 10, Detail 20 Mbps; clamped 2–100 Mbps). All presets now use VBR (Detail CBR removed), H.264 High profile is probed first (then Main / Baseline / VP9), and the H.264 level is chosen by pixel rate (4.2 / 5.1 / 5.2). Export files are typically 40–60% smaller with no visible quality loss.
Improved
Playback Lookahead in Browser Idle Time (`js/media/preview-cache.js`, `js/editor/editor-canvas.js`) Playback lookahead no longer renders uncached frames synchronously inside the `requestAnimationFrame` tick. It runs via `requestIdleCallback` only when the measured render cost fits the remaining idle budget, eliminating periodic stutter while the cache bar extends ahead.
Improved
Playback Hot-Path Cost (`js/media/preview-cache.js`) Occupancy checks are throttled (skipped during playback), `isAudioOnlyComposition` and `getBakingTimeRanges` are memoized during playback, audio-only frames count as cached so idle / lookahead workers stop when the bar is full, and ruler repaint during playback is throttled to 250 ms.
Improved
Measured Slow-Mo Audio Sync (`js/editor/editor-timeline-core.js`, `js/media/videocomp-enggine.js`) Audio rate now follows the timeline's real achieved speed (0.05 steps, 120 ms hold, down to 0.25x) with closed-loop drift trimming during slow-mo, and the master audio clock is released when not slaved so drift correction always applies.
Improved
Direct O(1) Audio-Only Span Caching (`js/media/preview-cache.js`) Genuine audio-only regions (e.g. the right-hand tail after all visual layers end) are cached instantly and painted green on the ruler, with a 1.5-frame safety margin so photo boundaries, cut seams and fades are never treated as audio-only.
Fixed
Missing Layers After Refresh (`js/editor/editor-canvas.js`, `js/editor/editor-media.js`) Layers skipped because their media was not decoded yet are now redrawn automatically (bounded retry), broken / never-hydrated image entries self-heal instead of staying cached, and image load invalidates the cache of every layer sharing the same media.
Fixed
Cut / Trim Frame Seams (`js/editor/editor-timeline-ops.js`, `js/editor/editor-canvas.js`) Cuts use the exact frame-quantized playhead time, trim snapping uses the snap target's exact seconds, and layer activity checks tolerate float noise, preventing 1-frame gaps or drops at split points and beatmarks.
Fixed
Idle Cache Crash (`js/media/preview-cache.js`) Fixed a call to a non-existent `scheduleRulerUpdate` method that threw a `TypeError` and aborted idle / prune steps.

Temporal Occupancy Partitioning & Void Realtime Bypass (`js/media/preview-cache.js`, `js/editor/editor-canvas.js`) Implemented Algoritma 5 (Temporal Occupancy Partitioning + Realtime Bypass) in `PreviewCacheManager`. Automatically partitions timeline durations into active visual intervals and void (empty / audio-only) spans via `rebuildOccupancyIntervals`. Completely bypasses idle caching loops on void spans, eliminating browser freezes and saving up to ~26 GB of GPU VRAM on mixed audio/visual projects. Void spans provide O(1) virtual cache hits (`hasFrame` and `getFrame`) using a shared background canvas, and timeline ruler cache bars for empty spans fill green instantly with a single `ctx.fillRect`.

New
Smart Look-Ahead Playback Caching (`js/preview-cache.js`) Introduced `startLookaheadWorker(fromSec, fps)` — during playback, a background worker pre-renders frames **ahead** of the current playhead into the RAM preview cache (default 1.5 s window, configurable via `window.cacheLookaheadSec`). Uses `MessageChannel` macro-tasks to fire reliably between `requestAnimationFrame` ticks without blocking the main render thread. The lookahead window slides forward with the playhead and auto-restarts only when the playhead advances past the worker's range. Worker stops cleanly on pause, scrub, or export.
